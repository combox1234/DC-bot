## 🤖 About ComBox
ComBox is a fully-featured Discord bot designed to supercharge technical interview preparation. Whether you are a computer science student prepping for placements or an experienced developer sharpening your skills, ComBox brings the coding environment right into your Discord server. 

It features a custom XP gamification engine, dynamic streak tracking, interactive DSA quizzes, LeetCode daily challenge integration, and even mock interview matchmaking!

## 🚀 Key Features & Important Commands

### 💻 LeetCode Integration
- `/lc link <username>` - Link your Discord profile to your LeetCode account.
- `/lc stats` - View your total solved problems, contest rating, and global rank.
- `/lc daily` - Get today's daily LeetCode challenge right in the chat.
- `/lc solved <slug>` - Log a solved problem to earn XP and build your streak.
- `/lc contest` - View the schedule for upcoming LeetCode contests.

### 🎮 Gamification & Streaks
- `/quiz start <category>` - Start an interactive quiz (DSA, Aptitude, Python, AI/ML, Verbal).
- `/leaderboard` - See who has the most XP in the server.
- `/streak` - Check your consecutive daily activity streak.
- `/stats` - View a complete breakdown of your engagement and accuracy.

### 🌐 GitHub Integration
- `/github link <username>` - Link your GitHub account to ComBox.
- `/github stats` - View your public repos, followers, and profile link.
- `/github commits <owner> <repo>` - Track the latest commits for any public repository.
- `/github structure <owner> <repo>` - Browse the file and folder structure of a repository.
- `/github file <owner> <repo> <path>` - Read the contents of a file directly in Discord.

### 🏢 Preparation Tools
- `/company <name>` - Access comprehensive recruitment guides and FAQs for top tech companies.
- `/interview join` - Enter the matchmaking queue to find a mock interview partner.
- `/notes add` / `/notes view` - Store and retrieve your personal study notes.
- `/remind set <time>` - Set a daily reminder to study and solve problems!
